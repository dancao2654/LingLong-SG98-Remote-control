# Remote Hardware Documentation

This directory contains locally cached vendor documentation for the remote
boards currently supported by `sg98-remote`.

Downloaded on `2026-04-20`.

## Folders

- [common-esp32-s3](./common-esp32-s3/README.md): shared ESP32-S3 chip-level
  references used by the supported remote boards
- [elecrow-crowpanel-1.28-rotary](./elecrow-crowpanel-1.28-rotary/README.md):
  Elecrow CrowPanel 1.28 rotary/touch remote board docs
- [waveshare-esp32-s3-touch-amoled-1.75](./waveshare-esp32-s3-touch-amoled-1.75/README.md):
  Waveshare 1.75 AMOLED touch remote board docs

## Notes

- HTML files are vendor page snapshots saved locally for offline reference.
- PDFs and CAD/source files are vendor-provided board or component documents.
- `common-esp32-s3/` avoids duplicating the same Espressif chip references in
  every board folder.
